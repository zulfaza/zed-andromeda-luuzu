# Andromeda Luuzu

Andromeda Mariana theme for [Zed](https://zed.dev), Luuzu variant.

## Install (dev extension)

1. Open the Extensions page in Zed.
2. Click **Install Dev Extension**.
3. Select this directory.

Then pick **Andromeda Mariana - Luuzu** in the theme selector.
